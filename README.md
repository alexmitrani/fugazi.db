# fugazi.db

`fugazi.db` is a data-only R package: cleaned, corrected reference data
behind the [Fugazi Live Series](https://www.dischord.com/fugazi_live_series)
- show listings, venue coordinates, tag/duration data, and discography
metadata - ultimately sourced from the FLS website and other sources.

It contains **no processing code**. Every table here is generated by the
companion package, [Repeatr](https://github.com/alexmitrani/Repeatr), which
holds all the raw inputs, cleaning/correction logic, classification, and
modelling - `Repeatr::export_fugazidb_data()` writes the files that ship
here. Repeatr also produces the derived/modelled datasets behind the
[Fugazetteer](https://alexmitrani.shinyapps.io/Fugazetteer/) Shiny app; this
package does not.

## Installation

```r
# install.packages("remotes")
remotes::install_github("alexmitrani/fugazi.db")
```

## What's here

Six lazy-loaded data objects - see `vignette("Data-Catalogue", package = "fugazi.db")`
for a full description of each table, its columns, and the keys used to join
them together.

| Object | Description |
|---|---|
| `fls_shows` | One row per show: date, venue, attendance, sound quality |
| `fls_venue_geocoding` | Venue coordinates |
| `fls_tags` | Per-track duration data, keyed by `gid`, parsed from personal MP3 tag exports |
| `releases` | Per-release metadata (release date) |
| `discography` | Per-song studio discography metadata (release, vocals, instrumental) |
| `played_with` | One row per show and band Fugazi played with, keyed by `gid` |

Each table is a fact table - corrected and reformatted, but not joined,
summarized, or modelled.

See Repeatr's `vignette("Rebuilding-the-Data")` for how this package's data
gets refreshed.
